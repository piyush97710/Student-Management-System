# Student Management System

A simple console-based Student Management System developed using Core Java.

## Features

* Add a new student
* View all students
* Search student by ID
* Delete student by ID
* Calculate average marks
* Display grade based on marks
* Show total number of students

## Technologies Used

* Java
* ArrayList
* OOP Concepts
* Scanner
* Conditional Statements
* Loops
* Methods


## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java files:

```bash
javac *.java
```

5. Run the project:

```bash
java Main
```

## How It Works

The application provides a menu where users can add, view, search and delete students.

Each student has:

* Student ID
* Name
* Age
* Marks
* Grade

The program also calculates the total number of students and their average marks.
